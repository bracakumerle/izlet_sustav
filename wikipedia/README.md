# iZLET — Wikipedia Sandbox Arhiva

Repozitorij Wikipedia članaka u pripremi.
Objava se vrši strateški — ne automatski.

## Workflow

DRAFT → u_izradi/ → spremno_za_objavu/ → objavljeno/

## Pravila

- Svaki članak mora imati minimalno 3 citabilna third-party izvora
- Niti jedan članak se ne objavljuje bez eksplicitne odluke Petra Kumerlea
- COI članci ne idu direktno — prolaze kroz neutralnog posrednika
- Svaki članak prati _status.md zapis
